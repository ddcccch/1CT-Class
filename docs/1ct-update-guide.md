# 1CT 分发与升级指南

> 结论：**便携版，发新压缩包让对方「先关 1CT → 解压覆盖 → 再打开」就行。用户数据不会丢。**

## 一、为什么升级不会丢数据

1CT 是**便携版**，程序和数据是分开的：

| 内容 | 位置 | 升级时 |
|---|---|---|
| 程序本体 | 解压出来的目录（`启动1CT.exe` + `1CT\`） | **替换掉** |
| 成员 / 配置 / 执行历史 / 兜底照片 / 登录态 | `%APPDATA%\1CT` | **不动，自动保留** |

所以覆盖程序目录 = 只换引擎，不碰油箱。

> **分发包不含账号数据**：压缩包里只有程序本体（`启动1CT.exe` + `1CT\`），没有 `%APPDATA%\1CT` 里的登录态、成员、密码、执行历史或签到缓存；收到包的人首次启动需要自己登录/添加成员。

## 二、升级三步

1. **先退出 1CT**
   - 托盘图标右键 → 退出 1CT（推荐）
   - 或任务管理器结束 `1CT.exe`
   - ⚠️ 不退出会失败：程序占用着 `1CT.exe` / `resources\app.asar`，替换会被拒绝
2. **整个目录替换**
   - 关掉旧的 1CT 目录，用新包解压出的 `启动1CT.exe` + `1CT\` **整体替换**
   - 不要只替换 `app.asar` 或只替换 exe（新旧文件混搭最容易出怪问题）
3. **重新双击 `启动1CT.exe`**

升级后第一次启动会自动做一次配置迁移（见下），不会弹窗打扰。

## 三、这次升级自动帮你改了什么

旧版 UI 允许手填校园跑的「有效窗口 / 里程 / 时长」，旧默认值是 `30 / 3000 / 30`。
新版这三项改成每天自动随机，但如果旧配置里存过这几个值，它们会继续压住随机逻辑，
看起来就像「更新没生效」。

所以新版本第一次启动时会做一次性迁移：

| 旧值 | 处理 |
|---|---|
| `windowMinutes = 30` | 清空 → 改为每天随机 39–48 分钟 |
| `runDistance = 3000` | 清空 → 改为每天约 1000 米且末位非 0 |
| `runTime = 30` | 清空 → 改为每天 31–39 分钟且非 5 的倍数 |
| 其它自定义值（如窗口 45、时长 25） | **保留不动** |
| 迁移标记 | 写 `migrations.unirunAutoV2`，只跑一次 |

## 四、怎么确认对方装的是新版

每个副本目录里有 **`VERSION-1CT.txt`**：

```
构建时间   : 2026-10-18T01:37:28
asar sha256: 9441ce85…
```

让对方发这个文件的前两行，就能确认版本，不用猜。

## 五、几个坑

1. **路径尽量别改**：如果他们把 `启动1CT.exe` 钉在任务栏/发了快捷方式，换目录会失效。覆盖同一路径最省事。
2. **不要两个目录同时留着跑**：1CT 有自己的单实例锁（在 `%APPDATA%\1CT`），两个目录只能开一个，开着第二个会直接退出。多留一份旧目录不影响使用，但容易点错。
3. **建议升级前备份一次用户数据**（不必须，但保险）：
   复制 `C:\Users\<用户名>\AppData\Roaming\1CT` 到别处即可。
4. **出问题怎么回滚**：把旧目录放回去，`%APPDATA%\1CT` 不用动（新版写入的字段旧版会忽略）。
5. **只发熟人**：这套东西没有自动更新、不上报任何数据，但发得越广越难收回来。

## 六、可以直接复制给同学的话

```
1CT 更新了，升级很简单：

1. 先把 1CT 退出（右下角托盘图标右键 → 退出 1CT）
2. 把新压缩包解压，用它里面的「启动1CT.exe」和「1CT」文件夹
   替换掉你原来的（整个换掉，别只换一部分）
3. 重新双击「启动1CT.exe」

你的成员、配置、签到历史都在系统用户目录里，升级不会丢。
如果提示文件被占用，说明 1CT 还没关干净，任务管理器结束 1CT.exe 再试。
```

## 七、这次版本的主要变化（给对方一句话版）

- 二课：拍照 / 定位签到全自动（图库没图用内置兜底照），签到码活动不再报名
- 二课已报名列表：改为直连官网「已报名」（`activityStatus=1`）并自动翻页，换电脑 / 覆盖更新后不再清零
- 已报名列表的签到/签退状态改为读取**官方报名列表**（`GetStuAllActApplyList`，`SignD`/`SignT`/`Inputdate`/`SignOutdate`，与官网「报名/完成列表」页同源），再以官方签到记录/活动详情兜底；官方已签到/已签退会正确显示，不再一律显示「—」
- 已报名列表每行显示**官方签到时段 / 签退时段**（活动详情 `ActivityQDDate`/`ActivityQTDate`），方便安排哪些时间段要开着电脑挂程序
- 「最近活动」改为**官网报名列表最近 6 个签到/签退成功记录**（官方时间倒序），表下标注数据来源；官网不可用时回退本机记录
- 二课会话过期时自动续期/重登一次（用成员页保存的学号密码），成功后卡片说明显示「已自动重新登录二课」
- 二课签到/签退：官网已报名的活动一律自动纳入跟踪（不受关键词限制），报名了就会继续签到/签退
- 已结束的二课活动自动归档，不再每轮重复拉详情（少请求、少刷屏）
- 校园跑：窗口、里程、时长全部自动随机（不用手填，也不会有 30/3000 这种整数被作废）
- 新增「记录」页：俱乐部报名/签到/签退 + 校园跑成功明细
- 界面精简：去掉了没必要的开关；窗口有最小化/最大化/退至后台按钮
- 图标全面换成 1CT（含任务栏/托盘）
